The Bazaar 皮肤工具与素材包 1.0.0

一、普通用户

1. TheBazaarModManager-Setup-1.0.0.exe
   推荐使用的皮肤管理器安装程序。已安装旧版时会自动升级。

2. TheBazaarModManager-Portable-1.0.0.zip
   免安装版本。与安装程序二选一即可，不需要重复下载。

3. 素材包
   - KotoneAlchemist-MakDefault-1.0.0.zip：藤田琴音 / Mak 默认皮肤。
   - DooleyChameleon-Default-1.0.0.zip：蜥蜴与墙莱士 / Dooley 默认皮肤。

使用方式：打开皮肤管理器，导入素材包 ZIP，部署后通过 Steam 启动游戏。
若游戏更新后提示适配器或原始文件不匹配，请不要强行覆盖，等待工具更新。

二、素材包制作者

TheBazaarAssetGenerator-Portable-1.0.0.zip 是免安装的素材包制作器。
解压后运行 TheBazaarAssetGenerator.exe。生成的 ZIP 仍由皮肤管理器负责导入、部署和恢复。

三、校验

每个发布文件旁边都有同名 .sha256 文件。校验值也汇总在 SHA256SUMS.txt。
本地构建未配置 Authenticode 证书时，Windows 可能显示未知发布者或 SmartScreen 提示。

GitHub 正式发布只包含两个软件的代码与构建产物；藤田琴音和蜥蜴素材包仅随网盘发布。
