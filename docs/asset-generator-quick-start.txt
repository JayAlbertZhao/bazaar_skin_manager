The Bazaar Asset Generator 1.0.0

1. Install The Bazaar Skin Manager 1.0.0 first.
2. Extract this ZIP to a normal writable folder.
3. Run TheBazaarAssetGenerator.exe.
   New projects write their asset-pack ZIP beside this executable by default;
   Advanced Settings can override the output path.
4. Select the target hero and supply the available character, background,
   and small-icon inputs. Empty optional inputs remain empty.
5. Adjust the shared character position or an individual output preview.
6. Generate the asset-pack ZIP, import it into Skin Manager, then deploy only
   while The Bazaar is closed.

The generator does not install a second runtime. Import and deployment reuse
the verified Skin Manager adapter and reversible backup path.

Public source and GitHub software archives do not bundle game artwork. Badge
generation therefore needs a locally prepared template directory selected in
Advanced Settings. Private/netdisk builds may include that local resource.
