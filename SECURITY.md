# Security

Please report a suspected unsafe path write, archive traversal, backup/restore
failure, or arbitrary-code execution issue privately through GitHub's security
advisory interface rather than a public issue.

The manager intentionally refuses unknown native game-file hashes. A Steam
update may therefore require a manager update before deployment is enabled.

Release installers should be downloaded from this repository's GitHub Releases
page and checked against the adjacent SHA-256 file. Authenticode status is also
shown by Windows when a signed release certificate is configured.
